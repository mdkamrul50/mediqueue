# Mediqueue 🎓

A modern tutor booking platform where students can find expert tutors, filter tutors by session date, and book learning sessions easily.

## 🌐 Live Website

https://mediqueue-two.vercel.app

---

## 🚀 Features

- 🔍 Search tutors by name instantly
- 📅 Filter tutors using session date range
- 👨‍🏫 Users can add new tutor profiles after login
- ✏️ Logged-in users can update their own tutor information
- 🗑️ Logged-in users can delete their own tutor posts
- 📖 View detailed tutor information
- 🗓️ Book tutor sessions with slot management
- 🔐 Secure authentication and protected routes
- 📱 Fully responsive design for mobile, tablet, and desktop
- ⚡ Fast and modern UI built with Next.js and Tailwind CSS
- 🌙 Beautiful glassmorphism inspired interface
- 🗄️ MongoDB database integration for dynamic data storage
